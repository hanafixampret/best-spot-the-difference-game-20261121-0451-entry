Twin Lanterns — a spot-the-difference game. Two near-identical pictures side by side, seven differences hidden in each of four hand-drawn procedural scenes (Lantern Festival, Koi Pond, Desert Caravan, Snowy Cabin). Click a difference, or steer the crosshair with the arrow keys and press Enter; H spends a hint, M opens a 2× magnifier lens, P pauses. Found differences wear gold rings on both pictures, the HUD counts how many remain, and each scene runs on a 3:00 timer with a score, accuracy and a best score kept between visits. Pure Canvas 2D, ES modules, no library and no network request — it runs offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
